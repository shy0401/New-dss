# 감축 근거표 (A1 조사표 정리, 규칙 v1, 2026-11-20)

근거표 세션(가)의 2번. 팀 전달 폴더의 `감축전략_효과통계_2026-11-10.xlsx` '근거 행' 543행을 근거표 CSV로 옮긴다. 값은 고치지 않고 열만 더한다. 근거 등급 차례 · 국외 실측 조건 · 수단의 층 · 추천 제외 기준은 수집 계획 3.1.1절(PC 문서 `project/working/methods/reduction-data-collection-plan-2026-11-19.md`, 저장소에 없음)(결과를 보기 전에 정한 것)을 그대로 따르고, 이 문서는 그것을 **행마다 기계적으로 적용하는 법**만 정한다.

- 범위: 조사표 543행(국내 365 · 국외 178) · 수치와 출처 주소만 옮김 · 사람 이름 없음
- 1~4절(옮기는 규칙)은 등급별 · 층별 수를 세기 전에 적었다. 미리 본 것은 열 이름과 분류 값의 종류(분류 24종, 지표군 6종, 근거 유형 7종, 국가 20곳)뿐이다. 결과는 5절부터

## 3. 줄이는 용도
조사표 `지표`를 그대로 옮기되 낱말만 맞춘다: 난방 → `난방 열` / 가스 → `가스` / 냉방 → `냉방` / 전기 → `전기` / 총에너지 → `총에너지` / 1차에너지 → `1차에너지` / 운영탄소 → `운영탄소` / 내재탄소 → `내재탄소` / 자립률·생산 → `발전량 · 자립률` / 비용 → `비용(절감률 아님)` / 기타 → `기타`.
- 분류가 조명·가전·승강기·공용부이고 지표가 전기인 행은 `전기(해당 설비)`로 적는다(단지 전체 전력의 %가 아님, `REDUCTION_INDICATORS.md` 3절)
- 용도의 몫(난방 열이 가스의 몇 %인지 등)은 여기 넣지 않는다. 지역 조건표의 일이다

## 4. 근거 등급 (수집 계획 3.1.1절의 차례를 행에 적용)
| 조건(조사표 열) | `근거_등급` |
|---|---|
| 근거군 = 실측, 국가 = 한국 | `실측_국내` (근거 유형이 "기관 실적"이면 `근거_유형` 열로 구분됨) |
| 근거군 = 실측, 국가 ≠ 한국, **장치 효율 수단** | `실측_국외_조건맞음` |
| 근거군 = 실측, 국가 ≠ 한국, 그 밖(외피 · 운영 수단) | `실측_국외_참고`. 공동주택 · 같은 난방 방식 · 비슷한 난방도일 셋이 **원문에서 다 확인된 행만** `실측_국외_조건맞음`으로 올리고 `비고`에 근거를 적음 |
| 근거군 = 설계·계산, 국가 = 한국 | `문헌_계산` |
| 근거군 = 설계·계산, 국가 ≠ 한국 | `가정` |
| 근거군 = 기업 발표 | `가정` |
| 근거군 = 기타 | `가정` |
| 위와 상관없이 지표군 = 비용, 또는 층 = 수단 아님 | `해당_없음`(절감률 근거가 아님) |

- 장치 효율 수단 = 3.1.1절이 든 것(조명 · 승강기 구동 · 보일러 효율 · 히트펌프 COP · 태양광 성능비)에 해당하는 행: 분류가 태양광 · 히트펌프·난방 전기화이거나, 분류가 조명·가전·승강기·공용부이거나, 분류가 보일러·난방 제어·배관이면서 글에 "보일러"가 있는 행
- 외피 · 운영 수단의 국외 실측은 조사표에 난방 방식 · 난방도일 열이 없어 표만으로는 조건을 확인할 수 없다. 그래서 기본값이 `실측_국외_참고`다(조건 미확인). 이것은 "안 맞음"이 아니라 "확인 못 함"이다
- 3.1.1절 ③은 "국내(또는 국내 공동주택을 모델로 한) 계산"이므로 국외 계산 · 기업 발표 · 기타는 ⑤(기관 추정 · 가정)로 묶었다. **이 묶기는 이 문서의 해석**이다(3.1.1절에 국외 계산 · 기업 발표의 자리가 따로 없음 → 메인 확인 필요)
- 대표값이 빈 행(수치 없음)도 등급은 같은 규칙으로 매기고, 값은 NULL로 둔다

## 5. 추천 제외 (3.1.1절 기준을 행에 적용)
| 조건 | `추천_제외` | `제외_까닭` |
|---|---|---|
| 층 = 행동 · 교체 | 예 | 계획 단계 밖(입주 뒤 행동 · 교체) |
| 분류 = 히트펌프·난방 전기화 | 예 | 적용이 거의 불가능(면담 `2 24:24`: 실제 COP가 3.0에 못 미침, 초기 비용) |
| 분류 = 태양열·지열·연료전지이고 글에 "지열"이 있음 | 예 | 적용이 거의 불가능(면담: 공사비 "한 100억") |
| 층 = 설비 | 따로 추천 안 함 | 설비 사양(단지 시공 세부). 상위 수단의 구성 요소로만 |
| 층 = 자재 · 시공(내재탄소) | 해당 없음 | 운영 감축 추천의 대상이 아님(시공 단계 참고 계산) |
| 층 = 수단 아님 | 해당 없음 | 수단이 아님 |
| 그 밖(층 = 계획) | 아니오 | — |

- "효과가 아주 작음(계획안 전체 배출의 1% 미만)"과 "지역 조건으로 안 맞음"은 계획안 · 지역마다 달라지므로 이 표에서 정하지 않는다(감축 계산에서 판정)
- 사다리 2단계 "에너지 절약 운영 −4.8%"와 '따로 본 값'의 세대 표시장치는 이 규칙으로 각각 "예(계획 단계 밖)" · "따로 추천 안 함"이 된다. 도구를 바꾸는 것은 사용자 확인 뒤(3.1.1절)이므로 표에는 규칙대로 적고 `비고`에 "도구 사다리 · 따로 본 값에 쓰이는 행(사용자 확인 대기)"이라고 남긴다

## 6. 원문 대조
- 대상: 지금 도구의 사다리 · 따로 본 값에 쓰이는 행. 조사표에서 같은 조건으로 다시 뽑아 중앙값이 도구 값과 같은지로 확인한다(운영 −4.8% = 운영·행동 × 실측 × 전기 6행, 신축 통합 −11.3% = 신축 통합 × 실측 × 총·1차에너지·운영탄소 14행, 열회수 환기 −3.5% 1행, 세대 표시장치 −11.7% 1행)
- 방법: 출처 주소를 열어 조사표의 수치(전 · 후 값 또는 %)가 원문에 있는지, 무엇의 %인지, 실측인지, 대상이 공동주택인지를 본다. 열리지 않으면 "대조 못 함"
- 대조 결과로 조사표 값을 고치지 않는다. 다르면 `원문_대조 = 대조함(다름)`과 원문 값을 `비고`에 적고 메인에 알린다
