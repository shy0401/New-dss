# 2026-11-21 지역 수집: 건축HUB 빈 응답 · 503 묶음을 넘기도록 다시 묻기 보강
- 관련: [K-apt 따로 된 차선](2026-11-21-region-kapt-separate-lane.md). 상세 수집 진행(저장소 밖, PC): `project/working/methods/region-expansion-2026-11-20.md` 7절
- 사용자 지시(2026-11-21): "보강 후 다시 띄우기"

## 왜 (실측)
- 대구 달서 · 양산에서 건축물대장(표제부) · 건축HUB 건물 에너지 단계가 "EMPTY_RESPONSE: API 빈 응답"으로 FAILED
- 실패 기록: 대장 달서 10200 5쪽(23:42) · 양산 10200 7쪽(00:55), 둘 다 HTTP 200 빈 본문
- 같은 쪽을 캐시 없이 다시 물음(01:0x): 양산 7쪽 2번 모두 정상(758건), 달서 5쪽 2번 모두 빈 응답, 10행씩 나눈 20쪽은 정상 14 · 503 3 · 빈 응답 3 → 쪽에 묶인 문제가 아니라 제공기관이 짧게 몰아서 실패. 같은 시각 공공데이터포털 점검(1회)은 정상
- 코드: 대장은 빈 응답을 일시 오류로 보지 않아 한 번에 단계를 멈춤(실패 응답은 1시간 캐시). 건물 에너지는 일시 오류로 보지만 4번 · 대기 합 12초라 몰린 실패를 못 넘김

## 무엇을 바꿨나
- `official.REGISTER_TRANSIENT`에 `EMPTY_RESPONSE`(건물 에너지 `TRANSIENT_CODES`와 같은 규칙, 10/10 밤에 세운 규칙: 자료 없음은 resultCode 03이지 빈 본문이 아님)
- 대장 · 건물 에너지 모두 다시 묻기 6번, 대기 2 · 4 · 8 · 15 · 30초(합 59초), 다시 물을 때 실패 캐시를 지우고 새 연결(대장도 `reset_connection`)
- 6번 다 실패하면 대장은 그 쪽만 실패로 적고 단계를 이어감(전과 같음), 건물 에너지는 단계 FAILED(전과 같음, 다시 실행하면 받은 쪽은 캐시)
