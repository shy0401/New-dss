# 2026-11-20 건축물 에너지효율등급 인증 출처 추가
- 관련: 기준 문서 2절(판 1.23), `backend/app/kea_rating.py`, `backend/app/cli.py`(`fetch-kea-rating`), `backend/tests/test_kea_rating.py`

## 왜
- 감축 근거는 국내 실측을 먼저 쓰기로 했다(사용자 결정 2026-11-19). 공동주택 감축 수단 가운데 "신축 기준 · ZEB · 효율등급"은 인증을 받은 단지와 받지 않은 단지의 **실사용량**을 비교하면 국내 실측 근거가 된다
- 인증 목록과 실사용량(K-apt · 건축HUB)을 묶은 공개 자료는 찾지 못했다(실측 자료 출처 조사, 2026-11-19, 웹 열람). 그래서 인증 목록을 받아 우리가 직접 잇는다
- 기준 문서 규칙상 새 출처는 받기 전에 2절에 등록한다

## 숫자 (2026-11-20, 이 PC에서 확인)
- 활용 신청: 자동 승인, 개발계정 하루 10,000건, 승인일부터 24개월(포털 화면)
- 첫 호출(1쪽 3건, 조건 없음): `resultCode` 00, `totalCount` **39,447건** → 100건씩 395번 호출, 하루 한도 안
- 응답 관찰: 값이 없으면 문자 `"NULL"`, `LOC_ADDR`에 시도가 없음(`RGN_SCT_NAME`에 있음), 예비인증 주소에 "일대" · 블록(BL) 표기가 있음. 3건 표본이라 비율은 받은 뒤 센다

## 결정
- 1차 에너지 소요량은 설계 평가값이므로 관측 표에 넣지 않는다. 쓰임은 ① 인증 단지와 비인증 단지의 실사용량 비교 ② 설계값 대비 실사용 비교(실현율)의 기준
