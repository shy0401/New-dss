- 관련: [참조 표를 저장소에 둠](2026-11-20-reference-tables.md), [지역 보정 관문](2026-11-20-regional-adjustment-gates.md)
- 규칙(결과 전에 적음) · 결과 · 스크립트(저장소 밖, PC): `project/tools/experiments/regional_guide/`(`README.md` · `fetch_kma_normals.py` · `build_guide.py`)
- 원본(PC): `data/raw/kma_normals/2026-11-20/`(일별 366개 JSON + 지점 일람표, MANIFEST에 크기 · sha256)

## 왜
- 사용자 구상(2026-11-20): 지역마다 꼭 맞는 방법은 불가능에 가까우니, 기후 · 기온 · 특징으로 "기준 배출이 대략 어느 방향으로 얼마나 다를 수 있는지" 알려 주는 가이드. 예: 대구는 여름이 더워 냉방이 많아 배출이 클 수 있다
- 지역 조건표는 DB에 기상이 있는 23곳뿐이라 전국 값이 필요했다(앞서 "B2 평년값 2안"을 닫으면서 정한 다시 볼 조건에 해당)

## 무엇을 했나
1. 기준 문서 2절에 출처를 **받기 전에** 등록(커밋 뒤 받음), 사용자 승인 뒤 기상청 기후표 조회로 일별 평년값 366일(2월 29일 포함) × 219지점을 받음(29 MB, 응답 그대로)
2. 지점 값: HDD18 · CDD24(기준 문서 5.10 기준온도, 평년 일평균으로) · 여름 / 겨울 평균기온 · 연 일조시간 · 여름 습도
3. 지점 → 시군구 269곳: 지점 이름 = 시군구 이름(광역시 지점은 그 시 전체, 없으면 같은 시도 · 같은 지역 구분 대표 지점)
4. 기준 배출 방향 가이드: 전주 단지 용도 몫 × 전주 대비 도일 비, 전주 2025 아파트 원단위 · 배출계수로 전기 · 가스를 합침
5. `backend/reference/regional_climate_guide.csv` · README · 시험, 기준 문서 판 1.32

## 숫자
- 지점 연결: 광역시 지점 71 · 지점 있음 185 · 대표 지점 12 · 연결 안 됨 1(세종, 지점 이름 '세종연서' — 확인 필요)
- 설계 지역 구분별 중앙값, 전주 대비 기준 배출: 중부1 +6.6% · 중부2 +2.0% · 남부 −3.3% · 제주 −11.4%(범위 −12.7~+10.4%)
- 대구: 여름 25.5℃(전주 +0.3℃) · 겨울 2.5℃(+1.1℃) · CDD 비 1.06 · HDD 비 0.89 → 배출 −2.9%. 공동주택 전기에서 냉방 몫이 6%라 냉방 증가보다 난방 감소가 큼
- **점검(미리 정한 규칙) 판정: 맞지 않음.** 남부 에너지 중앙값 −4.3% 대 정부 표준베이스라인 남부 ÷ 중부2 −11.9%, 차이 7.6%p(기준 ±5%p). 보조(중부2 중앙값 대비)는 −7.7%. 규칙을 바꾸지 않고 "가이드는 정부 기준보다 지역 차이를 작게 본다"로 적음
- 계산 · 저장값 · 화면 바뀜 없음(서비스는 아직 이 표를 읽지 않음)

## 바로잡은 것
- 첫 실행에서 지점 이름 끝의 '구'까지 떼는 코드 버그로 '대구'가 연결되지 않아 대구 9곳이 빠졌음 → 규칙('시' · '군'만 뗌)대로 고쳐 다시 냄. 점검 판정은 고치기 전(차이 5.2%p)과 뒤(7.6%p) 모두 "맞지 않음"
- 지점 일람표에 주소가 없고 지점 번호가 ASOS와 달라(전주 864) 연결 규칙 · 기준 지점 찾는 법을 도일 값을 보기 전에 다시 적음
