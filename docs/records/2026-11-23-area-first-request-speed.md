# 2026-11-23 지역 화면 첫 계산 속도: 대장 연면적 한 번만 읽기 · 지역난방 열 계산 기억
- 관련: `backend/app/energy_parcels.py`(`_register_area` 5분 기억), `backend/app/service.py`(`pooled_baseline`: 에너지 행 · 단지를 5분 기억, 단지는 쓰는 열만)
- 사용자: 합격 시험([기록](2026-11-23-status-new-plan-acceptance.md)) 한계 6(속도)을 발표 전에 손봄

## 왜
- 합격 시험에서 묶음 응답이 4~45초(수원 칸 45초 = 분석 25초 + 지역난방 열 17초), 화면 행정동 첫 계산 48초
- 프로파일(수원 칸, 첫 호출 38.7초): 분석 입력 중 `_register_area`가 해마다 6번 같은 지역 대장 전체를 읽어 26초. 지역난방 열은 요청마다 `pooled_baseline`을 두 번(개별 · 지역난방) 부르고, 한 번에 지역 에너지 행 4.5초 + 전국 단지 2.2만 개를 상세 열까지 3.8초 → 매번 17초(기억 없음)

## 무엇을 바꿨나
- 대장 연면적(지번 → 연면적 합)은 해와 무관 → 같은 시군구 묶음이면 5분 동안 한 번 읽은 값을 씀(분석 입력의 기억 시간과 같음, 새 대장은 5분 안에 반영)
- `pooled_baseline`: 지역 · 해의 에너지 행을 두 난방 방식이 함께 쓰고 5분 기억, 단지는 쓰는 6열만 읽어 5분 기억
- 계산식 · 값 바뀜 없음
