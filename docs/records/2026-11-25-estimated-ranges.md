# 2026-11-25 감축 제안에 추정 범위(L2): 단열·창호(가스) · 승강기 회생제동 · 옥상녹화 (계획 v3 단계 F)
- 관련: `backend/app/reduction_measures.py`(`estimated_ranges`), `area.py`. 앞 기록: [태양광 세 수준](2026-11-25-pv-three-levels.md)
- 계기: 사용자 — "추정"은 근거가 있어 적용하면 이만큼 줄 것이라고 근거와 함께 밝히는 것(2026-11-25). L2 도입은 사용자 결정(추천대로)

## 원칙 (바뀌는 것)
- 지금까지: "근거표 행의 값을 계획안에 곱하지 않는다". 이제: **값(감축 값 줄 · 목표 · 추천 방안)에는 곱하지 않고**, 원문 대조된 % 구간만 **추정 범위**로 따로 낸다(`data_class` ESTIMATED, 줄의 `estimate` 칸). 추정은 어떤 합계에도 넣지 않는다
- 추정 한 줄에 늘 다섯 가지: ① 근거(행 번호 · 원문 대조 · 등급) ② 곱한 양과 그 출처 ③ 결과 범위(kgCO2eq/년) ④ "추정" 표시 ⑤ 성립 조건

### 확인 (결과 보기 전에 정한 것)
- 감축 값 줄(태양광) · 목표 · 추천 방안 · 남는 양 · 녹지 상쇄 · 태양광 세 수준은 바꾸기 전과 같음(새 칸 `estimate` · `estimates`와 바뀐 `level`만)
- 사례 대상지 세 곳(600세대 · 신축 60,000 m² 주거 + 20,000 상업, 20층) 각각의 추정 범위를 표로 남김(사람이 읽고 상식에 맞는지 봄: 단열·창호 가스는 신축 주거 60,000 m² 가스 탄소의 9.8~17.3%, 승강기는 600세대 → 10.5~28.3대 → 4.1~16.1 t)
- 고정 사례 25개 같음
- 구현 중 더 정한 것(결과 보기 전): `shading`(외부 차양) 목표 수준 RANGE → INDICATOR(원문 대조 6행 중 공동주택 대상 없음), `boiler_heating_control` 목표 RANGE → INDICATOR(신축은 이미 의무)
