# 2026-11-23 새 지역 변화 예측 시험: 국토통계지도 100m 입력 없이 (실험만, 서비스 그대로)
- 관련: 실험 도구(이 PC `project/tools/experiments/`) `dev_eval.py` 모드 `_no100m` · `_regsub` · `_regform` · `_nolog`, `regform_build.py`, `run_u2a.sh` · `run_u2a2.sh`, `u2a_boot.py`. 결과 `eval/dev_units/u2a_*`. 서비스 코드(`deploy/team-model/server.py`)는 바꾸지 않음
- 사용자: "새로운 개발에 대한 예측 결과를 줄 수 있어야 하는데 예측을 줄 수 없다고 하면 안 됨", 사용자 활용 단계 계획 D1 가(우리 자료로 바꾼 모델을 시험)

## 왜
- 팀 변화 모델은 칸의 개발 전 상태 행이 있어야 예측함. 그 행의 입력 가운데 9개가 국토통계지도 100m(팀 자료, 국외 반출 금지, 팀 데이터셋 53곳만), 개발 전 배출량은 탄소공간지도 → READY 56곳 중 37곳은 예측 없음
- 새 지역에서도 예측하려면 이 입력 없이(또는 우리 자료로) 성능이 유지되는지부터 확인

## 방법
- 기준 A = 지금 서비스(37절 R2 · 후 해 입력 없음). 같은 학습 합본 · 지역 묶음 5겹 교차검증(CV) · 시험 10지역, 시드 0~5 · 6~11, 개발 단위(정식 표 `dev_units_v2_*`), 1,000 t 이상 개발(CV 220 · 시험 43)
- 1차(규칙: 시드 묶음 줄 두 개 모두, 37절 규칙 3): B 100m 9개 뺌 / C B + 대장 건물 수 · SGIS 500m 인구(표에 이미 있는 우리 쪽 출처 값) / D B + 개발 전 배출량 입력 뺌
- 2차(규칙을 결과 전에 고정: 12시드 평균 줄 + 시험 10지역 지역 단위 짝 재표집 4,000번에서 'A보다 +0.05 넘게 나쁨' 50% 미만): E C + 건축물대장 표제부로 만든 칸 · 해별 건물 형태(평균 건축면적 · 지상층수 · 높이 · 경과연수, 0 · 빈 값은 NULL) / E2 E − 높이 / F E − 개발 전 배출량
- 대장 형태 표: 팀 묶음 표제부를 지번 → 100m 칸(지번 면적이 가장 큰 칸) → 500m 칸, 52지역(전주 2구는 지번 → 칸 표가 묶음에 없어 빠짐, 학습 행 129,138/219,402에 값)

- 1차 실험 한 번은 3~4분(11-18 기준 실행의 26분은 그때 함께 돌던 수집 때문으로 보임)

## 읽는 법
- 국토통계지도 100m 없이도, 건축물대장으로 건물 형태를 다시 넣으면 지금 서비스와 같은 수준(시험 지역은 조금 나음). 개발 전 배출량(탄소공간지도)까지 빼도(F) 유지
- 즉 새 지역의 칸 상태를 **우리 자료(건축물대장 · SGIS · 용도지역 · 기상 · K-apt)만으로** 만들 수 있다는 실험 근거

## 남은 것 (서비스 반영 = U2-c, 기준 · 모델 변경이라 Draft)
- 새 지역의 대장 형태 · 대장 용도별 연면적 · SGIS · 용도지역 · 기상 · 단지 입력을 이 도구 DB에서 팀 표와 같은 정의로 만들고, 팀 표 지역에서 팀 값과 칸 단위로 대조
- 서비스: 학습 입력을 F(또는 E)로, 출발 행에 배출량이 없어도 되게(지금 `pick_row`는 학습에 쓸 수 있는 행만), 예측 구간(q10~q90) · 환산 계수 다시 계산, 대상지 규칙(29-2절) 확인
- 공개 주소: 국토통계지도 값이 학습 표에서 빠지면 공개 주소에서 예측을 막는 까닭이 사라짐(탄소공간지도 이용 조건은 확인 필요)
