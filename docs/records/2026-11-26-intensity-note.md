# 계획 배출 안내문: 용도별 원단위로 계산했으면 그렇게 적음 (2026-11-26)

- 계기: 발표 전 점검(사용자 "현재 프로젝트 상태로 발표를 진행해도 되는지 체크")에서 시연 화면을 캡처하다 발견
  - 시연 입력: 전주 기준 칸, 주거 60,000 m² · 600세대 + 상업 20,000 m²
  - 값: +1,633.7 t/년. 주거 30.23 · 상업 97.96 kWh/m²로 용도별 계산한 값이 맞음
  - "이 계획의 결과" 아래 안내문: "한 원단위(30.23)를 모든 용도의 계획 연면적에 적용했습니다. 용도별 원단위는 쓰지 않았습니다"
  - 원인: 11-23 용도별 원단위를 넣을 때 `plan_bundle.plan_emission_block`의 `intensity_note`가 조건 없이 옛 문장을 그대로 냄
- 바꾼 것: `_intensity_note`
  - 엔진의 부하 줄(`new_load_lines` · `removed_load_lines`)이 있으면 쓴 용도별 원단위를 적음. 예: "용도별 원단위로 계산했습니다(kWh/m²·년): 주거 30.23 · 상업 97.96. …"
  - 줄이 없으면 전과 같은 문장
  - 숫자는 엔진 줄에서만 가져옴
- 값: 바뀌지 않음(문장만)
