# 2026-11-20 지역 가이드에 공동주택 난방 방식 구성
- 관련: [근거표 요약 · 지역 가이드](2026-11-20-region-guide-evidence-screen.md), [지역 기후 가이드](2026-11-20-regional-climate-guide.md)
- 비포 · 애프터(저장소 밖, PC): `project/working/ui-preview/heating-mix/난방방식_비포애프터.html`
- 근거(저장소 밖, PC): `project/working/datasets/지역데이터셋_추가요소_분석.html`(가스 원단위 차이를 난방 방식이 66.4% 설명), `project/deliverables/presentation/발표준비_기록.md` 3절(두 데이터셋 점검)

## 왜
- 두 데이터셋 점검(2026-11-20)에서 지역 가이드의 남은 항목 중 우선순위가 가장 높았다. 단지 간 가스 차이의 대부분을 난방 방식이 설명하고, 지역 차이는 이 구성 차이에서 크게 온다
- 전국 자료(지역난방 공급 구역 · 도시가스 보급률)는 출처 확인 전이지만, 서비스 20개 지역은 K-apt 단지 기본정보에 난방 방식이 이미 있다

## 정한 규칙(값을 보기 전에 적음)
- 분류: 글에 '지역'이 있으면 지역난방, '개별'로 시작하면 개별난방(개별난방+기타 포함), '중앙'으로 시작하면 중앙난방, 그 밖은 기타. '-' · 빈칸은 미상으로 따로 세고 비율에 넣지 않음(0으로 채우지 않음)
- 비율: 세대 기준(난방 방식을 알고 세대수가 있는 단지). 단지 수도 함께. 없는 방식은 0 % 줄로 만들지 않음
- 범위: 분석 지역의 K-apt 단지 전체(구역이 아니라 지역). 값의 성격 = 관측(K-apt 등록 값), 소규모 공동주택 · 단독주택은 빠짐
- 읽는 법 문장은 이미 확인된 사실만: 단열·창호 가스 지표는 개별난방 117쌍 짝 비교 값(사다리 상수에서 문장을 만듦, 화면에 숫자를 따로 적지 않음), 지역난방 열의 탄소는 계산 범위 밖(지역난방 열 배출계수 없음)

## 무엇을 바꿨나

- 지역 화면 '지역 기후·지자체 계획 가이드' 칸에 "공동주택 난방 방식 (세대 비율)" 줄

## 숫자
- 계산 · 감축량 · 저장값 바뀜 없음(표시만)
- 지역별 세대 비율(같은 규칙으로 DB에서 센 값, 개별 / 지역 / 중앙 %, 단지 수 · 미상):
  - 지역난방이 큼: 세종 11 / 88 / 1(224곳 · 미상 3), 수원 25 / 73 / 2(458곳 · 2), 부산 강서 39 / 59 / 2(52곳), 서울 강동 37 / 50 / 12(152곳 · 1)
  - 개별난방이 거의 전부: 전주 95 / 1 / 4(364곳 · 3), 군산 92 / 0 / 5(158곳 · 1), 익산 88 / 11 / 1(175곳 · 3), 가평 100(21곳), 전북 군 지역 99~100
  - 논산(수집 일부)은 단지가 없어 줄이 나오지 않음(빈칸)
- 뜻: 세종 · 수원처럼 지역난방이 큰 지역은 단열·창호 가스 지표(개별난방 짝 비교)가 그대로 맞지 않고, 난방 열 탄소가 계산에 빠져 운영탄소가 작게 잡힌다 → 다음 판단 거리(아래)
