# 2026-11-22 조례 조회가 법제처 인증 실패로 조용히 '못 찾음'이 되던 것
- 관련: `backend/app/ordinances.py`(`AUTH_FAILED_TEXT` · `AUTH_FAILED_MESSAGE`, `collect_ordinance`), 기준 문서 판 1.53(2절 자치법규 행), `docs/NATIONWIDE.md`, 시험 `tests/test_ordinances.py`
- 사용자: "지금도 웹에서 유저가 개발 계획을 입력한 경우 동작이 다 되는거임?" → 점검에서 찾음 → "추천 방향으로 진행"(키는 사용자가 신청, 그동안 오류 표시부터)

## 찾은 것 (확인)
- 개발 계획 입력 점검(웹과 같은 API 10개 지역 · 보고서 · 구역 분석 · 화면에서 화성 계산)은 모두 동작. 그 화면에 "화성시 도시·군계획 조례를 받지 못해 시행령 상한"이 나옴
- READY 56곳 중 **37곳**이 '조례 못 찾음 → 국토계획법 시행령 상한'. 조례를 읽은 19곳은 모두 2026-09-27~10-27에 받았고, 못 찾은 37곳은 모두 2026-11-05~11-20에 받음. 같은 서울특별시 조례를 서울 강동(10-01)은 읽고 강남 · 송파 · 양천(11월)은 못 읽음
- 원인: `.env`에 법제처 키(`LAW_GO_KR_OC`)가 없어 기본값 `test`로 물음 → 지금 법제처 답 "사용자 정보 검증에 실패하였습니다. OPEN API 호출 시 사용자 검증을 위하여 정확한 서버장비의 IP주소 및 도메인주소를 등록해 주세요."(워커에서 직접 물어 확인). 코드는 이 답을 검색 결과 0건으로 읽어 "못 찾음"으로 적었음

## 고친 것
- 검색 답에 "사용자 정보 검증에 실패"가 있으면 `AUTH_FAILED`로 적고 문구를 "법제처 OPEN API 사용자 검증 실패(인증) — 키(LAW_GO_KR_OC)를 .env에 넣고 이 PC의 IP를 법제처에 등록해야 조례를 받습니다"로. 한 번 거절되면 같은 발행처를 더 묻지 않음
- 지역 준비 단계는 지금처럼 DONE(시행령 상한으로 확인 — 지역을 쓸 수 없게 막지 않음)이고 문구에 까닭이 보임
- `AUTH_FAILED`는 '최근 받음'으로 치지 않아(그 판정은 PARSED · PARTIAL만) 키를 넣은 뒤 다시 받으면 다시 물음
- 계산 · 계수 바뀜 없음

## 남은 것(사용자)
- 법제처 국가법령정보 공동활용 누리집에서 OPEN API 이용 신청(이용자 ID = OC) · 이 PC의 공인 IP 등록 → `.env`에 `LAW_GO_KR_OC=<ID>` → 워커 · api를 다시 띄움 → 37곳 조례 다시 받기
