# 2026-11-20 지역 자동 방안: 옥상 경고 · 넣기 버튼 · 발전량 없을 때
- 관련: [점검 반영](2026-11-20-audit-fixes.md), [운영 · 신축 통합 정리](2026-11-20-operation-newbuild-cleanup.md)
- 점검 문서(저장소 밖, PC): `project/working/methods/audit-2026-11-20-summary.md` 2절 A · B
- 비포 · 애프터(저장소 밖, PC): `project/working/ui-preview/area-rec/지역화면_감축방안_비포애프터.html`(사용자 확인 2026-11-20)

## 왜
- 2026-11-20부터 지역 자동 방안이 태양광만 남으면서(#26) 세 가지가 드러남(점검 A · B)
  1. 필요한 옥상이 계획보다 훨씬 커도 경고가 없었다. 전주 상업지역 · 계획 연면적 75,000 m² · 목표 20% · 건물 전체 기준에서 옥상 약 555,800 m²(연면적의 7.4배)를 그대로 보였다
  2. "이 방안을 아래 칸에 넣기"가 사용자가 넣은 신축 · 기존 %를 0으로 덮었다(자동 방안의 % 가 0이라서)
  3. 발전량 근거가 없으면 자동 방안 칸이 통째로 사라지고, 계산해 둔 상쇄 전력량(`offset_kwh`)이 화면 · 보고서 어디에도 나오지 않았다

## 무엇을 바꿨나
1. 계획 건물 지붕과 견줌: 계산 결과에 `plan_roof_m2`(동 수 × 동당 건축면적, 그렇게 넣은 계획만)를 두고, 자동 방안에 `plan_roof_m2` · `plan_roof_basis`(footprint 또는 floor_area) · `roof_over_plan`을 더함. 건축면적 합이 없으면 연면적과 견줌(1층으로 지어도 지붕은 연면적을 넘지 않음 → 위 한계). 가정을 새로 두지 않음
2. 필요한 옥상이 그보다 크면 화면에 경고, 지역 보고서의 `effort_rec` 근거 문장에 같은 문장(숫자 검증 대상)
3. 버튼 이름 "태양광 값을 아래 칸에 넣기", 태양광 칸만 채우고 신축 · 기존 % 는 그대로. 넣을 태양광 값이 없으면 버튼 숨김
4. 발전량 근거가 없어도 칸을 남기고 상쇄 전력량을 적음. 보고서 근거 문장도 같은 경우에 남김
5. 문구: 보고서 화면 설명(신축 통합 · 운영 · 열회수 · 공용부 조명 · 승강기는 값을 내지 않는 지표), 세대 표시장치 주의(에너지 절약 운영은 지표만). 사용자 설명서 · 안내 화면 문장

## 숫자
- 감축량 · 태양광 용량 · 저장값 바뀜 없음. 바뀐 것은 경고 · 버튼 동작 · 문구 · 근거 문장 한 문단
- 화면 예(위 사례): 경고 "필요한 옥상 약 555,800 m²가 계획 연면적(…) 75,000 m²보다 큽니다". 신축 30%를 넣은 뒤 버튼을 누르면 30%가 남아 합계 29,635.3 t(필요 28,874 t, 여유 761.3 t)
- 지금 자료는 20개 지역 모두 발전량 근거가 있어 3번 경우는 화면에 나오지 않음(시험으로 확인)
- 시험: 백엔드 480 통과 · 4 건너뜀, 화면 213 통과
