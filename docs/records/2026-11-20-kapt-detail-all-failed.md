# 2026-11-20 지역 수집: 단지 상세가 하나도 안 읽히면 단계를 FAILED로
- 관련: [지역난방 열 지사에 대구 달서 · 양산 추가](2026-11-20-district-heat-daegu-yangsan.md)
- 상세 수집 진행(저장소 밖, PC): `project/working/methods/region-expansion-2026-11-20.md` 7절. 사용자 지시 "진행"

## 왜
- 대구 달서구(27290) 상세 수집에서 단지 단계가 DONE인데 메시지가 "K-apt 단지 252개 (상세 0개, 상세 실패 252개)"였다. 상세 페이지가 난방 방식 · 주소를 주므로, 이대로면 그 지역 단지의 난방 방식이 모두 비어 지역난방 비중 · 지역난방 열(추정) · 난방 방식별 원단위가 나오지 않는다
- 같은 단지(A10019993) 상세를 수집 단계와 같은 방식(`_client` + `fetch_complex_detail`)으로 다시 부르면 정상("개별난방")이라 그때만의 실패로 보이지만, 실패 종류(예외 이름)가 저장되지 않아 원인을 알 수 없었다
- DONE이면 다시 실행해도 건너뛰므로(`force` 없이는) 빈 상태가 조용히 남는다

## 무엇을 바꿨나
- `region_prepare.step_complexes`: 목록에 단지가 있는데 상세가 하나도 읽히지 않으면 `FAILED`("상세를 하나도 읽지 못함, 다시 실행 필요", 첫 오류를 메시지에). 목록 값은 그대로 저장. 하나라도 읽히면 지금처럼 DONE이고 실패 수는 메시지에
- 실패 기록에 예외 이름과 함께 오류 문장 앞 80자를 남김
- FAILED이면 K-apt 에너지 단계(단지 단계가 먼저 필요)도 기다림(PENDING) → 단지 단계를 다시 돌리면 이어짐
- 시험: 전부 실패 → FAILED, 한 곳 성공 → DONE

## 숫자 · 화면
- 계산 · 저장값 바뀜 없음. 지역 화면의 단계 상태가 "끝남" 대신 "실패"로 보일 수 있음(같은 종류의 상태 표시, 화면 코드 그대로)
- 워커는 상세 수집이 끝난 뒤 다시 빌드(지금 다시 띄우면 돌던 수집이 끊김). 달서구는 수집이 끝나면 단지 · 건축물대장 단계만 다시 넣도록 걸어 둠
