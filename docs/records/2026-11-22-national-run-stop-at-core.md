# 2026-11-22 전국 수집을 핵심 지역 34위에서 멈춤
- 사용자: "수집은 핵심 수집까지만 진행 전부 받기에는 현실적인 시간이 부족할 듯"
- 관련: 우선순위 표 `backend/reference/region_priority.csv`, 앞 묶음 기록 [전국 수집 운영 고침 묶음](2026-11-21-national-run-ops.md)

## 왜
- 핵심 34위는 11-22 04:00 KST에 모두 READY. 나머지 169곳은 K-apt 약 14,000단지가 남아 키 하나(초당 약 0.9건, 같은 PC에서 더 빠르게 할 길 없음)로 약 52시간 더 걸림

| 항목 | 비포 | 애프터 |
|---|---|---|
| 워커 대기열 | 지역 작업 482개(차선 294 · 지역 188) + 감시 1 | 비움(워커를 세우고 `celery` · `unacked` · 차선 대기 · 잠금 키 삭제) |
| 핵심 밖 169곳의 남은 단계 | QUEUED 1,034 · WAITING 94(기상) · RUNNING 2 | `PENDING` + 멈춤 문구(`stopped_from`에 이전 상태). 감시 작업은 PENDING을 다시 넣지 않음 |
| 지역 상태 | PREPARING 173 | READY 56 · PARTIAL 169 · NOT_PREPARED 4 |
| 인천 새 구 4곳(이미 제외) | PREPARING(격자 실패, 나머지 QUEUED 22) | 남은 단계 PENDING + 제외 문구 → NOT_PREPARED |
| 11-22 09:05 기상 재시도 예약 | 94곳 | 대기열과 함께 지움 |

- 받아 둔 자료는 그대로(지우지 않음): 멈춘 169곳 중 VWorld · 건축HUB 끝난 곳 69, 기상 끝난 곳 75, K-apt 끝난 곳 0(청주는 일부 단지 · 달만 저장, 캐시도 남음)
- 멈춘 뒤 감시 작업 결과: 다시 넣은 것 없음. 진행 중 · 대기 단계 0
