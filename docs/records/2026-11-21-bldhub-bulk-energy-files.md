# 2026-11-21 지역 수집: 건축HUB 건물에너지를 대용량 파일이 있는 달은 파일에서
- 관련: [2025-01 파일 맞대기](2026-11-21-bldhub-bulk-file-test.md), 기준 문서 2절 · 판 1.43, `backend/app/bulk_energy.py`, `region_prepare.step_building_energy`
- 사용자: "다음 작업 진행해도 될 듯"(파일로 채우는 기능)

## 왜
- 같은 자료(2025-01 234,340 지번 값이 API와 모두 같음)를 API로 받으면 전국 2025년 약 69만 회 · 약 1~6일(2흐름 실측 초당 1.3~7.5회 — 제주 4,904회 62분, 남양주 3,343회 7분)
- 파일은 한 달 전국(전기 · 가스 두 개, 28MB)을 다 읽는 데 3.8초(192만 줄)

## 무엇을 바꿨나
| 항목 | 비포 | 애프터 |
|---|---|---|
| 지역 준비 `building_energy` | 분석 연도 12달을 모두 API로(미리 받기 2흐름 → 순차 저장) | 그해 전기 · 가스 파일이 다 있는 달은 파일에서, 나머지 달만 API. 12달이 다 있으면 API 요청 0 |
| 파일 읽기 | 없음 | `bulk_energy.read_month` · `import_months`: 원본 zip을 고치지 않고 읽음. 같은 달을 두 번 받았으면 나중 받은 날 폴더 |
| 단계 메시지 | "법정동·리 N곳, 요청 N회, 새 행 N" | "대용량 파일 N개월 새 행 N(이미 있던 값과 같음 N · 다름 N)", API 달이 있으면 그 요청 수도 |

### 파일 줄 → DB 줄 규칙 (2025-01 API 줄과 맞대어 정함)
- 한 지번이 도로명 주소마다 여러 줄(순번)로 나옴: 값이 같으면 한 줄로(API도 지번을 한 번만 줌, 2025-01 7,341곳 모두 같은 값). 값이 다르면 넣지 않고 `conflicts`로 셈(2025-01 0곳)
- 주소: 지번 주소(`platPlc`)와 도로명 주소(`newPlatPlc`)를 API 모양으로 만듦(번지 없는 주소 끝 공백, '산' · '블록', '지하491'처럼 붙여 씀, 여러 줄이면 가장 작은 순번의 도로명). 2025-01 234,340 지번 모두 API와 글자까지 같음. 이 주소는 연속지적도에 없는 지번을 VWorld 주소로 칸에 넣을 때만 씀
- 이미 있는 건축HUB(API) 줄은 덮지 않고 값만 비교(`same` · `different`). 같은 지번 · 달의 K-apt 줄은 API 수집과 같게 계량값으로 바꾸고 옛 값을 `replaced_source` · `replaced_usage_kwh`로 남김
- 음수 · 빈 값은 `usage_kwh` NULL, 원값은 `raw_record.useQty`. 제공기관 0은 0. 전북 2023-10 이전 달은 옛 코드(45xxx)로 찾음(API와 같은 규칙, 그 달 파일로는 아직 확인 못 함)
- 원본 파일 이름을 `raw_record.bulk_file`에 남김

## 고친 것
- 2025-01 기록에 파일 글자를 cp949로 적었는데 UTF-8이었음(20만 줄 엄격 판정: UTF-8 실패 0 · cp949 실패 20만). 그때의 값 맞대기는 숫자 열만 써서 결과는 그대로
