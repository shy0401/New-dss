# 2026-11-23 사용자 매뉴얼 4.6절을 새 지역 화면 흐름으로 (U6 초안)
- 관련: `docs/USER_MANUAL.md`(1.5절 표 한 줄, 4.6절, 실습 5.1 · 5.3 입력 줄), 그림 `docs/images/manual2/m2-43-area-plan.jpg` · `m2-44-area-result.jpg`(새로)
- 근거: [지역 화면 계획 한 번 넣기 → 결과 한 화면(U3 S5)](2026-11-23-u3-screen-one-plan.md)(#91) 위에 쌓음. 사용자 활용 단계 계획 U6 "사용 문서를 U3 흐름으로 다시 씀"
- 사용자: 밤 작업 계획 U6 초안, "시작(화면 Draft 포함)". 화면 Draft에 딸린 문서라 Draft

## 왜
4.6절이 옛 화면(단계 4개, 계획 조건 칸과 팀 변화 모델 칸에 연면적을 따로 입력, U4 전의 "옥상이 연면적보다 크다" 경고)을 설명하고 있었음.

## 무엇을 바꿨나
- 단계 6개(①구역 고르기 ②계획 넣기 ③결과 ④감축 방안 ⑤배치·상한(선택) ⑥보고서)로 다시 씀
- "계획 넣기" 입력 표: 용도별 신축 줄 · 철거 줄 · 층수 · 동수 · 동당 건축면적 · 몇 년 뒤, 계산 설정(목표 · 기준 건물 · 발전량). 옛 링크는 "용도 미정" 한 줄로 받고 변화 모델을 돌리지 않음
- "결과": 한 줄 결론 · 세 범위 표(더하지 않음) · 팀 변화 모델 카드(1,000 tCO₂e 미만 방향만, 팀 표 없는 지역은 대신 값, 안내 주소에서는 이 PC 화면에서만) · 지역난방 열 한 줄 · 필요한 노력 · 행정동 비교
- "감축 방안": 목표 기준 둘과 지붕 한도(U4, 기준 문서 5.9 · 5.15)로 고침
- "보고서": 용도 줄이 있으면 변화 예측 절
- 과거와 현재 · 개발 전후 설명은 내용 그대로 맨 아래 "근거 자료" 접힘 아래로 옮김
- 링크 복사: 용도 줄 열쇠(`uses=` · `ruses=` · `years=` · `floors=` · `buildings=` · `footprint=`)
- 실습 5.1(J01) · 5.3(J03)의 입력 줄을 새 칸 이름으로. 결과 값 표는 그대로(원단위 계산은 같은 연면적이면 같은 값)
- 1.5절 표: 팀 변화 모델을 쓰는 곳에 "지역 시뮬레이션 → 결과"

## 확인
- 문서에 적은 동작은 S5 가지를 실제 화면으로 확인한 것(#91 기록): 묶음 응답 뒤 예측, 목표만 바꾸면 예측 다시 안 함, 화면 = 보고서 값
- 새 그림 두 장은 그 확인 때 찍은 것(전주 송천1동, 신축 80,000 m² · 목표 30%)
- 숫자 · 계수 · 기준: 바뀐 것 없음

## 남은 것
- 나머지 그림(m2-18 요약 막대 · m2-23 필요한 노력 · m2-25 감축 수단 · m2-27 보고서)은 옛 화면 그대로: S5 병합 뒤 다시 찍기
- 화면 안 "사용 방법"(`/guide`)과 `docs/USAGE.md`는 아직 옛 흐름: 화면 변경이라 S5 병합 뒤 따로
- 지역 보고서 지우기 버튼(#86)은 이 묶음에 없어 적지 않음
