## 무엇을 바꿨나
- 준비하지 않은 지역은 모든 엔드포인트에서 404와 까닭(전역 처리). 반경 구역 좌표 없음은 422 "중심 좌표가 필요합니다"
- 팀 모델: 시간 초과는 504 "230초 안에 답하지 않았습니다 … 칸 수를 줄여 주세요", 꺼짐은 503(전과 같음). 예측 대기를 230초로(nginx 240초 안). 잰 값: 전주 64칸 구역 예측 28.6초(42칸 사용 · 22칸 제외)
- 팀 모델 서비스의 예상 밖 오류 문구를 한국어로(전에는 `Type: message` 영어 그대로)
- 목록: `GET /api/scenarios`, `/api/reports`, `/api/area-reports`에 `?region=`. 지역 없이 저장된 옛 계획안은 격자로 지역을 찾음(`record_region` = 저장할 때와 같은 `region_for_grid`). 옛 계획안 78개의 격자 지역: 전주 59 · 완주 6 · 지역 행 없는 격자 13(→ 전주). 지역 없는 옛 지역 보고서 5개는 지역 목록에서 빠짐(조건 없는 목록에는 그대로)
- 지우기: `DELETE /api/scenarios/{id}`(결과 · 3D 이미지 함께), `/api/reports/{id}`, `/api/area-reports/{id}`. 보고서는 계획안을 사본으로 가지므로 계획안을 지워도 보고서는 그대로. 화면 버튼은 아직 없음(화면 변경은 승인 뒤)
- 공개 주소(게이트웨이 머리말 `X-Public-Gateway: 1`)에서 403: 수집 시작(`/api/collections`, `collection/missing`, `v1/collection-jobs`, `regions/{code}/prepare`, `regions/national/collect`), `system/offline`, `model/validate`(모델 다시 맞추고 기록을 씀), `standard/check`(무거운 점검), `uploads/*`, 모든 DELETE. 계획 · 최적화 · 보고서 · 분석 · 지도 열기 · 3D 이미지 · 팀 모델 경로는 그대로
