- 사용자 결정으로 팀원 키를 `KAPT_ENERGY_EXTRA_KEYS`에 넣고(PR #67의 기능) 워커를 다시 띄움(16:06 KST)
- 두 키에 한 건씩 직접 물음: 둘 다 결과 코드 00(키는 정상)
- 고양(41280, 463단지)에서 함께 돌림: 추가 키 흐름이 **65건 받은 뒤 사유 04(HTTP_ERROR) 연속 5건으로 멈춤**(16:18), **주 키 흐름도 16:17:32부터 멈춤**

- 조치: `.env`의 추가 키 줄을 주석으로 끄고 워커를 다시 띄움(16:25, 추가 키 0). 코드는 남김(다른 IP의 PC에서만 의미, 확인 필요). 기준 문서 판 1.47
