## 보류 · 확인 필요
- 사업자 둘 이상이라 보류: 성남(한난 + 나래 위례, 그대로) · 서울 송파(한난 수서 · 일원/가락 · 문정 · 장지 + 나래 위례 · 거여마천) · 화성(한난 동탄 + 휴세스 + 안산도시개발 송산그린시티)
- 공급자 모름: 대구 서구(편람의 서구 사업자는 산업단지뿐, K-apt 지역난방 13.9%)
- **수원(이미 연결된 곳)**: 같은 편람에서 휴세스가 호매실 · 당수를 공급(지정)해 사업자가 둘. 2026-11-20 연결 때는 표 II-2의 한난 수원 · 광교만 봄 → 규칙대로면 보류. 바꾸면 수원 숫자(기록 district-heat-carbon: 581.4 t)가 빠짐 → 사용자 결정
- 편람은 2020년 실적 → 그 뒤 사업자 바뀜은 확인 필요. '미정' 지정 지역(고양 장항 · 일산테크노밸리, 용인 언남, 과천 공공주택지구 등)은 세지 않음
