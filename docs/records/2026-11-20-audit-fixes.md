## 무엇을 고쳤나
1. **인증키 노출**: `kea_rating.py`가 HTTP 4xx/5xx나 연결 오류를 만나면 httpx 오류 문장(요청 주소에 인증키 포함)이 그대로 올라갔다. 메인 세션이 500 응답으로 재현함. 이제 주소 없이 쪽 번호 · 상태 코드만 적고 원래 예외를 잇지 않는다(`from None`). 시험 1개 추가. 실제 수집(39,447건)은 오류 없이 끝나 키가 찍힌 적은 없음
2. **기준 문서 2절 미등록**: 받은 뒤에도 2절에 없던 영국 NEED · ZEB 인증 현황 · 지자체 기본계획 3줄을 등록(판 1.28). 가스공사 도일은 받은 뒤 등록됐음을 이력에 적음
3. **옛 현재 설명**: 사용자 설명서(지역 자동 방안 "신축 20% → 기존 5%" → 태양광만, '지표만' 정의), 한계 문서(신축 11.3% · 열회수 3.5%를 곱한다는 문장), 사용법(사다리에 운영 단계), 기준 문서 5.15(지운 `RECOMMENDED_*`), 감축 지표 문서(사다리 단계 번호, 새 단지 전기 문장)
4. **시험 픽스처**: 보고서 화면(23.6% → 13.7%, 신축 통합 `alone` → 지표만), 지역 화면(신축 20% · 기존 5% → 태양광 2,220 kW만), 보고서 API(첫 단계에 운영이 올 수 없음)
5. **근거표 숫자**: 기록의 등급별 숫자가 행 수임을 적고 고유 수(실측_국내 87 · 문헌_계산 110)를 더함
