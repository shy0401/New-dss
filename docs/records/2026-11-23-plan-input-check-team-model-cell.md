## 고친 것
- 격자 예측이 시 코드(예: 수원 41110)로 팀 모델에 물어 404("팀 데이터셋에 지역 … 없습니다(53개 지역만)")였음. 팀 데이터셋은 구 단위 표(수원 권선구 41113 등)라서. 구역 예측은 이미 칸이 든 팀 표의 지역(`_model_region`)으로 묻고 있었음 → 격자 예측도 같게(팀 격자 자료가 없으면 지역 코드 그대로)
- 확인(api 다시 지은 뒤): 수원 → 41113 권선구 표 811.8 tCO2e, 고양 → 41281 덕양구 404.1, 용인 → 41465 수지구 629.7, 전주 · 송파 그대로, 강남은 그대로 404(팀 데이터셋에 없음)
