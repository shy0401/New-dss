# 2026-11-20 세대 표시장치(IHD·HEMS)를 '따로 본 값'에서 지표만으로
- 관련: [근거표 요약 · 지역 가이드](2026-11-20-region-guide-evidence-screen.md)(여기서 찾은 어긋남), [운영 · 신축 통합 정리](2026-11-20-operation-newbuild-cleanup.md)(같은 까닭의 앞선 결정), 기준 문서 5.15(판 1.34), [감축 지표와 근거](../REDUCTION_INDICATORS.md)
- 비포 · 애프터(저장소 밖, PC): `project/working/ui-preview/hems/세대표시장치_비포애프터.html`

## 왜
- 근거표는 이 수단을 "따로 추천 안 함"(층 = 설비, 설비 사양은 상위 수단의 구성 요소로만)으로 적었는데 도구는 계획안 전력에 −11.7%를 곱한 '따로 본 값'을 내고 있었다
- 사용자 결정(2026-11-20): 추천(지표만으로) 방향, 애매하면 두 방향을 다 해 보고 판단

## 두 방향 견줌
| | 그대로(따로 본 값) | 지표만 |
|---|---|---|
| 근거 | 국내 실측 1건(2010년, 64가구 · 겨울 2개월, 설치 전후, 대조군 · 기온 보정 없음, 청주의 '전'은 스마트미터만 단 기간). 원문 숫자는 일치 | 같음 |
| 근거표 규칙 | 어긋남(설비 → 따로 추천 안 함) | 맞음 |
| 앞선 결정과 | 어긋남: 효과가 세대가 보고 줄이는 행동을 거치는데, 같은 까닭으로 에너지 절약 운영(대조군 실험 근거가 있었음)을 지표만으로 내렸다 | 맞음 |
| 계획안 숫자 | 보고서 '수단별 효과' 표에 값(시험 예: 전력 400,000 kg의 11.7% = 46,800 kg) | 이 줄만 "지표만". 사다리 · 필요 감축량 · 지역 자동 방안은 원래 이 값을 쓰지 않아 그대로 |
- 판단: 애매하지 않음 → 지표만. 근거 1건이 약하고 규칙 · 앞선 결정 모두 지표만 쪽

## 무엇을 바꿨나
- `reduction_measures.py`: `use` alone → indicator, `base` electricity → 없음(값은 지표 글로만), 지표 글 "전력 −11.7% (−15.9~−7.5%, 설치 전후 · 대조군 없음)", 주의 문장에 까닭과 근거 한계
- 보고서 화면 설명 문장: "따로 본 값(세대 표시장치 등)이나 값을 내지 않는 지표(…)" → "값을 내지 않는 지표(신축 통합 기준, 에너지 절약 운영, 세대 표시장치, …)"
- 근거표 13-022 행 `비고`의 "사용자 확인 대기"를 결정으로 바꿈. 기준 문서 5.15 · 판 1.34, 감축 지표 문서, 설명서, 시험

## 숫자
- 사다리 밖에서 값을 내는 수단: 1개 → 0개. 사다리 · 필요 감축량 · 저장값 바뀜 없음
- 이미 만든 보고서에는 그때 값이 남음(보고서는 만들 때 값을 저장)

## 남은 것
- 근거표의 다른 7행 `비고`에 "사용자 확인 대기"가 남아 있음(운영 등 이미 결정된 행). 표 정리 때 함께 고침
