# 2026-11-19 지역 화면에서 구역(여러 칸) 개발의 배출 변화를 예측

- 범위: 팀 변화 모델 서비스 · 백엔드 · 지역 시뮬레이션 화면 (모델 로드맵 7-C · 7-B2)
- PR: #17(처음 #16, PR #15 병합 뒤 기준 브랜치가 지워져 닫혀 다시 엶). 바탕: [변화 모델을 개발 단위로 평가하고 서비스 · 화면에 반영](2026-11-19-dev-unit-model.md)(PR #15) 위에 쌓음

## 왜
- 개발은 대부분 여러 칸이다(2014 → 2024 개발에서 늘어난 연면적의 66%가 10칸 이상 개발). 화면은 칸 하나만 예측했다
- 모델 성능은 개발 단위로 쟀으므로, 화면도 한 개발 전체를 넣고 개발 합계를 보여 줘야 쓰임과 맞는다

## 진행 순서와 결정
1. 계획 입력 변환 점검(7-C): 계획으로 넣으면 칸 하나씩 본 큰 사례의 예측 합이 실제의 0.854배였다. 원인은 새 건물 건축면적 가정(주거 20층 · 비주거 5층)이었다. 학습 자료 값으로 바꾼 판은 판정 기준을 넘지 못해 넣지 않았다(아래 숫자)
2. 칸 배분 규칙: 개발 합계를 칸에 같게 나눠도 칸별 실제 배분과 비슷했다 → 같게 나눔을 쓴다
3. 화면 자리와 입력(사용자 결정, 사용성 기준): 지역 화면 패널 / 자료 없는 칸은 빼고 나머지에 나누되 화면에 적음 / 위 계획 연면적을 기본값으로(고치기 전까지 따라감), 용도 4줄까지
4. 화면 경로를 과거 개발로 맞춰 보다가 서비스 문제 두 가지와 기준 해 문제를 찾아 함께 고쳤다(아래)

## 숫자 (기준 · 출처)
- 계획 경로, 개발 단위(학습 합본 지역 5겹 교차검증, 범위 안 1,000 t 이상 개발 220개, 시드 0~5 · 6~11)

| | 오차 중앙값 | ±50% 안 | 예측 합 ÷ 실제 합 |
|---|---|---|---|
| 관측 입력 | 0.305 · 0.311 | 70.5 · 69.5% | 0.99 |
| 상세 계획(지금 서비스) | 0.303 · 0.324 | 70.9 · 71.8% | 0.95 |
| 상세 계획(새 건물 형태 고친 판, 넣지 않음) | 0.306 · 0.315 | 70.9 · 72.7% | 0.93 |

- 칸 배분(시험 지역 여러 칸 개발 24개, 참고 수준): 같게 나눔 0.221 · 79% · 0.979, 칸별 실제 배분 0.226 · 83% · 0.950
- 화면 경로 맞춤(시험 지역 개발 5개: 2 · 4 · 8 · 9 · 22칸, 개발의 전 해 · 기간으로): 서비스 구역 예측과 실험(같게 나눔) 값의 차이 0.1 t 이하
- 응답 시간: 22칸 12초, 26칸 14초
- 빠지는 칸(52개 지역 42,746칸): 어느 해든 쓸 수 있음 93.6%, 2024년에 쓸 수 있음 50.7%, 쓸 수 있는 해가 없음 6.4%(그중 빈 땅 396칸)
- 기준 해 자료만 없는 칸을 가까운 해로 채우기(시험 지역 개발 24개, 칸 하나씩 없다고 가정한 149경우): 오차 0.130 · 합계 비 0.956, 빼기 0.161 · 1.036, 모든 칸 있음 0.124 · 0.961
- 전주 혁신동 같은 계획: 기준 해 2019년 규칙 +10,071(22칸) → 2021년 규칙 +14,912 tCO₂e/년(21칸). 기간이 달라 계획 밖 변화가 다르게 들어감
- 인천 검단 3×3 구역(빈 땅 7칸)에 주거 200,000 m²: +2,722 tCO₂e/년
- 출처: 연구 기록 `performance-candidates` 40 · 41 · 42절, 모델 로드맵 6절

## 하지 않은 것 · 보류한 것과 이유
- 새 건물 형태를 학습 자료 값으로 바꾸기: 개발 단위 교차검증에서 기준(두 묶음 모두 0.02 이상 좋아짐)에 못 미침(+0.003 · −0.009). 처음 시험에서 크게 좋아 보인 것(0.196 → 0.123)은 결손 칸을 되살려 늘린 개발 표를 잘못 쓴 결과였다
- 빠진 칸을 지도에 따로 칠하기: 지도 코드를 바꿔야 해서 이번에는 칸별 표에 이유를 적는 데서 그침
- 기준 해 자료만 없는 칸을 그 칸의 가까운 해로 채우기: 미리 정한 두 번째 조건(합계 비가 1에 더 가까움)을 못 넘어 꺼 둠(`TEAM_AREA_NEAREST_YEAR=off`). 채우기는 모든 칸이 있을 때와 거의 같아, 조건을 바꿀지는 결정 대기
- "계획이 없을 때"와의 차이(계획만의 효과): 넣지 않음. 개발이 없던 칸 31,526개 해 쌍(시험 지역)에 빈 계획을 넣어 실제 배경 변화와 비교했더니 예측 합이 실제의 2.77배, 지역 × 기간 150묶음 합계 순위 상관 0.06, 묶음 오차가 "변화 없음(0)"으로 둔 것보다 큼(1,889 t 대 1,784 t). 미리 정한 세 조건을 모두 못 넘음

## 남은 일 · 한계
- 결과에는 계획 밖 변화가 들어 있다. 예: 전주 혁신동(26칸 중 21칸, 기준 2021년)에 주거 50,000 m²를 넣으면 +14,912 tCO₂e/년(2021 → 2028)으로, 이미 짓던 건물이 차는 몫이 크다. 계획만의 효과는 배경 변화를 맞히지 못해 따로 보이지 않는다(위)
- 기준 해가 "지금"보다 이를 수 있다(전주 혁신동 2021년). 2024년 상태를 쓸 수 있는 칸이 51%뿐이다
- 같게 나눔은 구역이 개발 부지를 고르게 덮을 때를 가정한다. 넓은 행정동에 작은 개발을 넣으면 칸마다 아주 작은 값이 들어간다
- 64칸까지만 받는다(평가한 가장 큰 개발)
- 개발이 없는 칸의 작은 배경 변화는 맞히지 못한다. 넓은 구역에 작은 계획을 나눠 넣으면 칸마다의 오차가 더해지므로, 구역은 개발 부지에 맞게 고르는 것이 좋다
