# 2026-11-20 녹지 흡수 근거 설명 고침(값 1.0 그대로)
- 관련: `backend/app/reduction_plan.py`(보고서 가정 문장), `backend/app/reduction_measures.py`(greenery 설명 · 출처), 기준 문서 5.15(판 1.27), [감축 지표와 근거](../REDUCTION_INDICATORS.md) 5절 · 출처
- 근거(저장소 밖, PC): `project/working/methods/reduction-evidence-table-2026-11-20.md` 9 · 11 · 12절, `project/tools/experiments/reduction_evidence/a8/fulltext_checks.csv`(감축 근거표 세션이 논문 본문을 확인하고 메인 세션이 행 · 출처를 대조함)

## 왜
- 녹지 흡수 1.0 kgCO2/m²·년은 숲 기준 계수의 낮은 쪽을 쓴 가정이고, "조경 녹지는 더 작을 수 있다(확인 필요)"로 남아 있었다. 국내 조경 실측을 본문까지 확인해 그 확인 필요를 채웠다
- 중간에 "실측의 4배"라는 비교가 나왔으나 분모가 달라(부지 전체 면적당) 틀린 비교였다. 같은 분모끼리만 견준다

## 무엇을 바꿨나
| 항목 | 비포 | 애프터 |
|---|---|---|
| 값 | 녹지 면적 × 1.0 kgCO2/m²·년 | 그대로 |
| 근거 설명 | 숲 기준 계수의 낮은 쪽, 조경은 더 작을 수 있음(확인 필요) | 숲 기준 계수의 낮은 쪽이고 국내 조경 식재지 실측(식재 면적당 0.38~2.37 kgCO2/m²·년) 범위 안. 부지 전체 면적당 값과는 견주지 않음. 새로 심은 나무는 처음 10년쯤 더 작음 |
| 보고서 가정 문장 | "…낮은 쪽이며, 조경 녹지는 숲보다 나무가 성기어 더 작을 수 있습니다(확인 필요)." | "…낮은 쪽이고, 국내 조경 식재지 실측(식재 면적당 연 0.38~2.37 kgCO2/m²) 범위 안입니다. 새로 심은 나무는 처음 10년쯤 흡수가 작아 계획 초기에는 이 값보다 작을 수 있습니다." |

## 숫자(본문 확인, 탄소 값에 × 44/12)
- 도시공원 식재유형별 연 흡수 1.04 · 2.12 · 6.47 · 3.67 tC/ha(분모 = 식재 면적) → 0.38~2.37 kgCO2/m²
- 분모가 다른 값: 공공용지 부지 면적당 0.65 tC/ha = 0.24, 공동주택 단지 110곳 부지 면적당 1.1 tC/ha ≈ 0.40(수관 면적당 1.83) kgCO2/m². 공동주택 단지 논문은 출판사가 자동 열람을 막아 메인 세션은 직접 열지 못했다(근거표 세션이 본문 HTML을 읽음)
- 조경수 수령별 연 흡수(표 6, 수령 10년): 느티나무 2.6 · 왕벚 1.9 · 잣나무 1.2 · 소나무 1.7 kg/그루(탄소 기준으로 보임, 확인 필요)

## 하지 않은 것
- 값 1.0을 바꾸지 않았다: 녹지 면적당 국내 실측은 없고, 식재 면적당 실측은 0.38~2.37로 넓게 퍼져 있어 어느 쪽으로도 바꿀 근거가 약하다
- 계획 초기(식재 후 10년)의 흡수를 따로 계산하지 않았다(수령별 식을 넣는 일은 따로)
- 계산 · 저장값 · 화면 바뀜 없음(보고서 가정 문장만)
