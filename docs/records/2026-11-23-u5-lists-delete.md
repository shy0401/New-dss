# 2026-11-23 사용자 단계 U5(작은 것): 이 지역의 계획안 · 보고서만 보이기와 지우기 버튼
- 관련: 화면 `frontend/src/components/DeleteButton.tsx`(새), `pages/ReportsPage.tsx`(계획안 · 작성 이력), `pages/AreaPage.tsx`(`ReportPanel` 최근 지역 보고서), `lib/api.ts`(204), `styles/components.css`, 시험 `components/DeleteButton.test.tsx`
- 사용자: 밤 작업 계획의 U5 작은 항목, "시작(화면 Draft 포함)". 화면 변경이라 Draft, 승인 뒤 병합

## 왜
U0(#78)에서 목록 API에 `?region=`과 지우는 API를 넣었지만 화면은 그대로였음.
| 화면 | 전 | 문제 |
|---|---|---|
| 검토 보고서 · 계획안 목록 | `GET /api/scenarios`(지역 상관없이 최근 30개) | 다른 지역 계획안이 섞여 최근 30개 안에 이 지역 것이 밀려남 |
| 검토 보고서 · 작성 이력 | `GET /api/reports`(최근 50개) | 같음 |
| 지역 시뮬레이션 · 최근 지역 보고서 | `GET /api/area-reports`(최근 50개 중 6개) | 같음 |
| 세 목록 모두 | 지우기 없음 | 시험으로 만든 계획안 · 보고서가 쌓이기만 함 |

## 무엇을 바꿨나
- 세 목록을 `?region=<지금 지역>`으로 물음. 지역을 고르지 않은 상태(`null`)는 원래 지역 `52110`(전주)로 물음(`DEFAULT_REGION`). 지역 없이 저장된 옛 지역 보고서 5개는 지역 목록에서 빠짐(U0 규칙 그대로)
- 지우기 버튼(휴지통): 계획안마다, 지역 보고서마다, 열어 둔 계획 보고서 옆에. 누르면 그 자리에 "…을(를) 지울까요? 되돌릴 수 없습니다. [지우기] [그만두기]"가 뜨고, 한 번 더 눌러야 `DELETE`를 보냄. 브라우저 확인 창은 쓰지 않음. 지운 뒤 목록을 다시 읽고, 열려 있던 그 보고서는 닫음. 공개 주소에서는 서버가 403으로 막고 그 문장을 버튼 옆에 보임
- `api()`가 본문 없는 204를 JSON으로 읽다 실패하던 것: 204면 읽지 않음(지우기 API 셋 모두 204)

### 전 → 후 (작은 항목이라 캡처 대신 목록)
| 어디 | 전 | 후 |
|---|---|---|
| 계획안 줄 끝 | "이 계획안" 표시만 | + 휴지통 → 그 자리 확인 |
| 작성 이력 | 고르기 상자만 | 보고서를 열면 상자 옆에 휴지통 |
| 최근 지역 보고서 줄 | 제목 · 날짜 · 방식 | + 휴지통 |
| 목록 범위 | 모든 지역 | 지금 지역(미선택은 전주) |

## 확인
- 지금 서비스 API(이 PC)로 잰 목록 수: 조건 없음 계획안 30 · 계획 보고서 50 · 지역 보고서 17 → `?region=52110` 30 · 50 · 12, `?region=41130`(성남) 0 · 0 · 0
- 미리보기 화면(포트 5420, 지금 API): 요청이 `/api/scenarios?region=…`, `/api/reports?region=…`, `/api/area-reports?region=…`로 나감. 전주에서 작성 이력 보고서를 열면 휴지통이 뜨고, 누르면 확인 문장이 뜨고, "그만두기"로 닫힘(실제로 지우지는 않음). 지역 시뮬레이션의 최근 지역 보고서 6줄에 휴지통
- 시험: `DeleteButton.test.tsx` 2개(두 번 눌러야 DELETE · 204를 성공으로 · 그만두기는 요청 없음 · 403 문장 보임). 화면 시험 222개 통과, `tsc -b` 통과
- 숫자 · 계수 · 기준: 바뀐 것 없음

## 하지 않은 것과 까닭
- 새 지역 분석연도 기본값을 자료 있는 해로: 지금 기본 2025년이 이미 자료 있는 해였음. 대시보드 `coverage_score`로 확인: 성남(41130) 2025년 1.0 · 2024년 0.0, 장수(52740) 두 해 0.5, 종로(11110) 두 해 0.0. 2025년보다 나은 해가 없어 기본값은 그대로 둠. 해마다 "자료 없음"을 선택 상자에 표시하려면 지역 · 연도별 자료 유무를 주는 API가 먼저 필요함(확인 필요, 다음 작업 후보)
- 지역 선택 상자의 준비 상태 표시: 이미 상세(DETAILED) · 기본(BASIC) · 없음으로 묶어 보여 줌(`AnalysisScopeBar.groupRegions`), 새로 할 것 없음
