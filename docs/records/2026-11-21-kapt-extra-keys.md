# 2026-11-21 K-apt 에너지에 추가 키를 함께 쓸 수 있게
- 관련: `kapt_energy.extra_keys` · `start_extra_key_prefetch` · `collect_kapt_energy`, `.env.example`(`KAPT_ENERGY_EXTRA_KEYS`), 기준 문서 2절 · 판 1.46
- 사용자: "api 키 입력 받을 항목 하나더 추가해 / 팀원거 받아서 보내줄게 … 내가 수집을 위해서 받고 사용하는 거니까"

## 왜
- 전국 수집(핵심 지역 34위까지)의 병목은 K-apt 월별 에너지 하나. 이 키는 순간 상한이 초당 약 1건(같은 키 2흐름 합계 1.88건은 50건 뒤 사유 04로 10분 막힘, 2026-11-21 시험)
- 이 PC에서 더 빠르게 할 다른 길은 없었음(누리집 에너지 화면 비공개, 대용량 파일 없음, 같은 사람 두 번째 계정 불가 — 수집 범위 문서 6절)

## 무엇을 바꿨나
| 항목 | 비포 | 애프터 |
|---|---|---|
| 키 | `DATA_GO_KR_SERVICE_KEY` 하나 | + `KAPT_ENERGY_EXTRA_KEYS`(쉼표로 여러 개, K-apt 월별 에너지에만) |
| 흐름 | 주 키 하나가 단지 목록을 앞에서부터 | 추가 키마다 한 흐름이 **뒤에서부터** 캐시를 채움(키마다 1.1초). 주 흐름은 만나는 지점부터 캐시를 읽어 빨리 지나감. 저장 · 규칙은 주 흐름 한 곳 그대로 |
| 멈춤 | — | 추가 흐름은 주 흐름을 만나면, 연속 5건 오류(막힘)면, 그 키의 하루 한도면 멈춤. 못 받은 몫은 주 흐름이 받음. 재시도 차례는 주 키만 |
| 기준 문서 | "한도를 피하려고 키를 여러 개 돌려 쓰지 않음" | K-apt 에너지만 예외(사용자 결정), 약관 확인 필요 · 키 값은 `.env`에만 |

## 확인할 것
- **효과**: 제한이 키마다면 키 하나당 초당 약 1건이 더해지고, IP마다면 같은 PC에선 빨라지지 않음 → 키를 넣은 뒤 두 키로 짧게(각 1.1초) 시험해 오류 없을 때만 그대로 둠
- **약관**: 공공데이터포털 인증키를 발급받은 사람 말고 다른 사람이 쓰는 것에 대한 약관 확인 필요(키를 준 계정이 정지될 수 있음)
- 키 값은 저장소 · 기록 · 대화에 쓰지 않음(사용자가 `.env`에 직접 넣음)

## 시험
